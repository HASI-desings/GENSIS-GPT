# GENSIS-GPT / GENESIS

3D AI Civilization Simulator prototype with 100 citizens, live needs/resources/events, city monitoring, first-person and third-person possession, citizen inspection, WASD movement, and installable PWA behavior.

## Controls
CITY = whole-city view; THIRD = follow selected citizen; FIRST = inhabit selected citizen; WASD = move; T/F/C = view shortcuts; Space = pause.

## Assets
Runtime uses Quaternius Universal Base Characters and Universal Animation Library assets, both released as CC0. The supplied local Standard packs were also used to validate the rig/animation setup during development.
